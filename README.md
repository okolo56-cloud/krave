# EventFlow

A seamless event management platform for hosts and attendees.

## Features
- Host dashboard with registrations and check-in metrics
- Create and publish events
- Attendee registration with instant digital ticket IDs
- Fast check-in search by name, email, or ticket ID
- Responsive desktop/mobile UI
- Browser localStorage persistence for demo use

## Deploy
This is a static single-page app. It can be deployed directly to Vercel from the repository with no server configuration.
